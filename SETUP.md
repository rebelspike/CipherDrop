# CipherDrop Setup

## Bootstrap requirements
- Python 3.11+ recommended

## Start
### macOS/Linux
```bash
./start.sh
```

### Windows PowerShell
```powershell
.\\start.ps1
```

Choose Standalone, Server, or Development mode. The first run creates `.env` locally with a random session secret. `.env` is excluded from Git.

> This is the initial project bootstrap. The application services will be added in the next implementation stage.
