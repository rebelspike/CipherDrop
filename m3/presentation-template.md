## Requirements Checklist

- [ ] Length is between **5 and 8 minutes** (videos outside this range receive a deduction)
- [ ] All team members speak — each person presents a portion
- [ ] Narrated clearly and audibly throughout
- [ ] Follows the slide deck structure
- [ ] Includes a live or recorded **demo segment** showing the application running
- [ ] Demo segment shows at least one security property working (e.g., rate limiting, encryption at rest, RBAC)

---

## Suggested Outline

| Time | Speaker | Content |
|---|---|---|
| 0:00–1:00 | All | Introduction — team, application name, problem it solves |
| 1:00–2:30 | Architect | Architecture and security design overview |
| 2:30–4:30 | Engineer | Live demo — primary user flows and security properties in action |
| 4:30–6:30 | Auditor | Security audit findings — what was found, fixed, and what remains |
| 6:30–8:00 | All | Lessons learned from agentic coding; what you would do differently |

---

## Tips

* Record using Zoom (local recording), OBS, or macOS QuickTime screen capture
* Do a test recording to check audio levels before the final take
* Speak to the camera or microphone, not the screen — viewers cannot see where you are looking
* You do not need professional production quality — clarity and content are what matter
* Upload to YouTube as "Unlisted" so it is accessible only via this link but not publicly searchable
